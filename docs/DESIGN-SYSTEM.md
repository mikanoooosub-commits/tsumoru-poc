## 0. 画面の骨格(WO-022)

| 幅 | 並び |

- 状態・計算の呼び出し・Server Action の呼び出しは `EstimateTool.tsx` に置き、画面の部分は `src/components/estimate/` の部品に分ける(§4 の表)。

## 2. 文字

書体: **Zen Kaku Gothic New**(デッキの Claude Design 版と同じ・代表の決定)。`layout.tsx` の `next/font/google` でビルド時に取り込み、自分のサーバーから配る(`--font-zen`)。日本語の字は subsets に無いので `preload: false`・`display: swap`。読み込むまでは `"Hiragino Kaku Gothic ProN","Yu Gothic","Meiryo"` で出す。太さは **400 と 700 の2種だけ**。行間 1.6。数字は等幅(`font-variant-numeric: tabular-nums`)。

## 5. 状態の表し方

| 状態 | 表し方 |
|---|---|
| 成功 | `✓` + 「…しました」(`role=status`)。登録・更新は閉じずに表示し、新規はフォームを初期化。記録の札は「✓ 記録済み」 |
| 失敗 | `!` + 「エラー: …」+ `--danger` 地(`role=alert`)。何が・どうすればを書く。DBの内部の文面は出さない(P-007) |
| 実行中 | ボタンの文字を「記録中…」「検索中…」「登録中…」「削除中…」に変え、無効にし、回る印(`.spin`・`aria-hidden`・動きを減らす設定では止める)を添える |
| 空 | 「まだ記録がありません。…」のように次の行動を書く。絞り込み0件は別の手がかり(番号・種類)で絞れることを書く |
| 無効 | 入力を無効にし、理由の文を直前に置いて `aria-describedby` で結ぶ(例: 叩き台を出す前の記録欄) |
| 古くなった | 条件が変わった帯(§4)。色だけでなく「▲ 条件が変わりました」の字で |
| 削除の確認 | その場に「E-042 を削除しますか?」+「やめる」(左)「削除する」(右)。行を `--danger-soft` にする。「はい」は使わない |
| 仮・不明 | 「仮」「不明」の字+淡色の札。数値の隣に置く |
| 想定外の障害 | `error.tsx`(「表示できませんでした」+もう一度)・`not-found.tsx`。英語の既定の画面を出さない |

## 6. 文言の決まり

- ボタンは**動詞**で(「確定金額を記録する」「メモを検索する」)。「OK」「はい」「記録」「検索」だけにしない。
- 同じものは同じ呼び名: 「過去見積」「叩き台」「確定金額」「補正理由」「手戻り」「根拠」。取り消すは「やめる」、消すは「削除する」。
- 金額は「¥11,791」(`yen()`)。叩き台の単価は小数4桁(`unit4`)、根拠の案件の単価は小数1桁(`unit1`)、数量差の調整は小数2桁。整形は `estimate/format.ts` に集め、**計算はしない**。
- 画面に**内部の記号・基盤の名前・内部の言葉を出さない**(「§6」「Neon」「系統でスコア」「地場の自社資産」など。WO-022 で外した)。
- 必須は「必須」の字で示す(`*` だけにしない)。
- 数値・出典・「仮」の注記は、文言を直すときに変えない。
- ~~画面・文書に「AI」「RAG」「意味検索」と書かない(D83)~~ → 2026-10-20(WO-023・D88)から: **意味検索は誇張なく書く**。書いてよいのは「AI の埋め込み(Voyage AI)で文の意味の近さを測り、根拠の選び方に足す」「金額の出し方は同じ」。書かないのは「AI が見積を作る」「学習する・賢くなる」「RAG」(文を生成していない)と効果の数字。メモ検索は今までどおり「語句の一致」。
- **出典より強く言い切らない**。ネット印刷で「注文できる・価格が出る」ものを「対象外」「出せない」と書かない(WO-017・D71)。
