# DESIGN-SYSTEM — つもるの画面の決まり

- 版: 2026-10-13(WO-009-2)/ 対象: `src/app/globals.css`・`src/components/EstimateTool.tsx`・`src/app/layout.tsx`・`error.tsx`・`not-found.tsx`
- 元: `proposal/design-tokens.md`(印刷版デザインシステム v1.1・D54)。**値はその表が正**。つもるは値を写して使い、`globals.css` の `:root` の1か所で定義する。
- 作り方の基準: `jp-business-ui`(色・文字・部品・状態・文言・アクセシビリティ)。点検の記録は [design-audit.md](design-audit.md)。
- 使い手: 見積担当(`assets/persona.md` ②・宮下さん)。慎重で、確認を省かない人。画面は「何を・どこまで確かめたか」が分かることを優先する。

## 1. 色(1か所で定義し、変数だけを参照する)

画面のスタイルは `var(--名前)` だけを使う。**色の値(#xxxxxx)は `:root` 以外に書かない**(`globals.css` を `grep` して確認する)。TSX には色の値を書かない。

## 2. 文字

書体: `"Hiragino Kaku Gothic ProN","Yu Gothic","Meiryo",system-ui,sans-serif`(tokens §3)。太さは **400 と 700 の2種だけ**。行間 1.75。数字は等幅(`font-variant-numeric: tabular-nums`)。

| 変数 | px | 役割 |
|---|---|---|
| `--fs-num` | 40(375px 幅では `--fs-num-sm` の 32) | 叩き台の金額(700・`--accent-text`) |
| `--fs-xl` | 24 | ブランド名(`h1`) |
| `--fs-lg` | 18 | カード・ダイアログの見出し(`h2`) |
| `--fs-md` | 16 | 本文・入力・ボタン・ラベル |
| `--fs-sm` | 14 | 注記・チップ・脚注・表の補足(**下限。これ未満は使わない**) |

注記が収まらないときは**文を削る**。文字は小さくしない。

## 5. 状態の表し方

| 状態 | 表し方 |
|---|---|
| 成功 | `✓` + 「…しました」(`role=status`)。登録・更新は閉じずに表示し、新規はフォームを初期化 |
| 失敗 | `!` + 「エラー: …」+ `--danger` 地(`role=alert`)。何が・どうすればを書く。DBの内部の文面は出さない(P-007) |
| 実行中 | ボタンの文字を「記録中…」「検索中…」「削除中…」に変え、無効にする |
| 空 | 「まだ記録がありません。…」のように次の行動を書く。絞り込み0件は語を変える案内 |
| 無効 | 入力を無効にし、理由の文を直前に置く(例: 叩き台を出す前の記録欄) |
| 削除の確認 | その場に「E-042 を削除しますか?」+「削除する」「やめる」。「はい」は使わない |
| 仮・不明 | 「仮」「不明」の字+淡色のチップ。数値の隣に置く |
| 想定外の障害 | `error.tsx`(「表示できませんでした」+もう一度)・`not-found.tsx`。英語の既定の画面を出さない |

## 6. 文言の決まり

- ボタンは**動詞**で(「確定金額を記録する」「メモを検索する」)。「OK」「はい」「記録」「検索」だけにしない。
- 同じものは同じ呼び名: 「過去見積」「叩き台」「確定金額」「補正理由」「手戻り」。取り消すは「やめる」、消すは「削除する」。
- 金額は「¥11,791」(`yen()`)、日付は使っていない。
- 画面に**内部の記号・基盤の名前を出さない**(文書番号「§6」、「Neon」など)。それらは docs に書く。
- 必須は「必須」の字で示す(`*` だけにしない)。
- 数値・出典・「仮」の注記は、文言を直すときに変えない。
- 文面の検査は `natural-wording` で行う(§8 に結果)。

## 7. アクセシビリティの基準

| 項目 | 基準 | 確かめ方 |
|---|---|---|
| 文字のコントラスト | 本文 4.5:1 以上(大きい文字 3:1) | 全テキスト要素を計算(`docs/test-scenarios.md` 末尾の計測) |
| 部品の枠 | 3:1 以上(入力・ボタンは `--muted` = 4.83:1) | 同上 |
| 押せる大きさ | 44×44px 以上 | 全部品の外形を測る(375px と 1024px) |
| フォーカス | 全部品で 2px の `--ink` の輪+オフセット 2px。`outline: none` を使わない | Tab で一周する |
| ラベル | 全入力が `label` で結ばれている | `labels.length` を数える |
| 横スクロール | 375px で出ない | `scrollWidth <= innerWidth` |
| 構造 | `h1` 1つ・`main` 1つ・`lang="ja"` | |
| 色だけに頼らない | 状態は 色+記号+文字 | 白黒にして読める |

## 8. 検査の記録(WO-009-2・2026-10-13)

計測の結果は [test-scenarios.md](test-scenarios.md) 末尾「画面整備後の計測」に記録した。natural-wording の検査結果と、変更前後のスクショは WO-009-report.md に記録した。

## 9. 変えるとき

1. 値を変えるときは design-tokens.md を先に直す(正)。つもるの `:root` はそれに合わせる。
2. 画面の部品を足す前に、§4 の部品で足りないかを確かめる。
3. 色を足したくなったら、PM に上げる(新しい色は発明しない)。
4. 直したら change-log・test-scenarios を同じ回で合わせ、画面は 375px と 1024px で測り直す。
