# 画面案の評価(柏木 修・社長兼営業の目で)

前提として、7案とも中身の数字は同じです。そのため、どの案にも同じように当てはまる引っかかりを先にまとめます。案ごとの評価では、その案に特有の点だけを書きます。

## 全案に共通する引っかかり(数字の出し方)

- **電卓で検算すると合わない。** 内訳には「4.2円/部 × 3,000部 = ¥12,529」とありますが、4.2×3,000は12,600円です。中央値4.0に+4%を掛けると4.16円で、これだと12,480円になります。どちらでも12,529円にはなりません。社員に検算されたら、その時点で「この機械はいい加減だ」と言われます。端数の扱いをどこかに書いておいてほしいです。
- **根拠の4件が全部4色(4C)。** 色はどの件も「×」です。特色1色の仕事なのに、4色の仕事の単価から値段を出しています。特色はインキを調色しますし、刷り出しの色合わせもあるので、手間のかかり方が4色とは違います。色が違うのに類似度92%と出るのは、点の付け方が甘く見えます。一覧には E-035「特色1C封筒」があるのに使われていない理由も、画面からは分かりません。
- **30,000部の単価(E-037・2.6円)を3,000部の中央値に混ぜている。** 部数が10倍違えば、1部あたりの単価は別物です。いちばん似ている E-003 は同じ3,000部で5.5円なのに、叩き台はそれより24%安くなっています。画面にも理由は書いてありますが、私なら E-003 を軸にします。担当者が「安すぎませんか」と聞いてきたら、私は答えにくいです。
- **型・版代が「別途」。** 特色1Cなら刷版は必ず要ります。合計の数字が実際より軽く見え、担当がそのままお客さんに出してしまう心配があります。
- **数量の調整が「仮ルール」。** 仮のルールで出した数字は、お客さんには出せません。
- **粗利率が画面に出ている**(過去案件の粗利と、想定粗利率37%)。これだと画面をそのままお客さんに見せられません。お客さんに説明するときは、画面を見ながら私が口で話すしかありません。
- **「自動で完結しない条件」の枠の中身は、ネット印刷1社の事情。** 「ダイレクト/PDF/スマートチェック」「45kg用紙は不可」は、うちの値付けには関係ありません。私には「ネットでも特色は人手がかかる、だからうちの出番だ」という話として読めます。ただ、見積担当にとっては読むだけの文章になります。
- **「推奨納期 約4.5営業日」。** お客さんに半日単位の納期は言いません。
- **確定金額の欄の見本「31000」。** 叩き台12,529円の倍以上なので、ぎょっとします。特に案2と案4は右寄せで濃いめに見え、最初から入力済みに見えます。
- **押した後のことは画像からは分かりません。** 叩き台を見積書として印刷・PDFにできるのか、版代を足して合計を出し直せるのか、です。

## 案1

- **第一印象**: 紙の見積書の下書きを机に置いたような画面。左の紺色の帯が重たい。

1. **使わせたいか: 迷う。** 真ん中が紙の見積書の形になっていて(四隅のトンボ風の線)、担当が「見積を作っている」感覚を持ちやすいです。一方で、真ん中の「価格根拠」が長い文章です(PC_1of2の下半分〜2of2の上)。担当が毎回これを読むとは思えません。
2. **説明できるか: ある程度できる。** 内訳表の「刷り代 推定単価4.2円/部 × 3,000部(根拠の単価2.6〜5.5円/部)」の1行と、右の「根拠にした控え」4枚を使います。ただ、根拠が文章なので、指で差して説明できる所が少ないです。
3. **信用できるか: 共通の点以外では、普通。** 右の控えのカードに「×色」「×数量帯」がはっきり並んでいるのは正直で良いです。気になるのは、PC_1of2右上の「根拠にした控え」と真ん中の「価格根拠」に同じ数字が二度出てくることです。どちらを見ればいいのか迷います。
4. **業務の道具に見えるか: 見える。** 一覧PC(表+削除の確認が行の中に出る)も台帳らしいです。スマホは4枚分と長く、メモ検索が一番下の紺色の箱にあって探しにくいです(スマホ_3of4〜4of4)。

## 案2

- **第一印象**: 左に条件、真ん中に根拠、右に金額の3列。ちゃんとした業務ソフトらしい。

1. **使わせたいか: はい(条件つき)。** 右の列に金額・内訳・合計・確定記録が縦にまとまっていて、担当が最後に何をすればいいかが分かります。根拠の案件は「開く/閉じる」で畳めて、畳んだ状態でも「一致しなかった項目: 色・数量帯・流用」が見えるのが良いです。ただ、PC_1of2では目が「左→真ん中(根拠)→右(金額)」と動き、肝心の金額が一番右にあります。慣れるまで迷いそうです。
2. **説明できるか: できる。** 右列の「単価の出し方」です。「中央値4.0円/部 → 数量差の調整+4% → 4.2円/部」と矢印で順番に書いてあり、口で説明しやすいです。真ん中の類似度の棒グラフも見せやすいです。
3. **信用できるか: 普通。** 内訳に「合計 ¥12,529」の行があり、見積らしく締まっています。ただ、合計の上の刷り代が4.2×3,000なので、検算のずれ(共通の点)が一番目立つのもこの案です。PC_1of2右下の確定金額欄の「31000」は、右寄せで入力済みに見えます。
4. **業務の道具に見えるか: 見える。** 一覧PC(表・絞り込み・手戻りの札)もそのまま台帳として使えます。スマホ(1of3〜3of3)は上に「1条件/2叩き台と根拠/3記録」の切り替えがあり、一番下には金額と「確定金額を記録する」が常に出ています。外出先で確認するには一番分かりやすいです。ただ、確定金額が空のまま、オレンジのボタンが常に目の前にあるのは、押し間違いが少し心配です(押した後どうなるかは分かりません)。

## 案4

2. **説明できるか: できる。一番やりやすい。** ①〜④の数字の流れと、「根拠の単価の並び」の横棒と中央値の点線(PC_2of2右上)を使います。案5と同じ中身ですが、白地なので印刷しても読めそうです。棒に金額が書いていない点は案5と同じなので、足してほしいです。
3. **信用できるか: 共通の点以外は、比較的信用できる。** 計算が①〜④に分かれているので、「どこで4.0が4.2になったか」は追えます。ただ、③の「×数量3,000部=刷り代 ¥12,529」で検算が合わない点が逆に目立ちます(PC_1of2右下)。

## 順位

1. **案6** — 計算が①〜④の番号順になっていて、担当に値付けの考え方を渡せます。お客さんにも横棒で「真ん中を取った」と見せられ、見た目も落ち着いています。
2. **案4** — 一画面で金額と確定記録が済み、スマホも短いです。粗利を隠したまま見せられるのはこの案だけです。ただ、根拠が畳まれていて担当が開かない心配があるので2位にしました。
3. **案2** — 業務ソフトとして一番まとまっていて、スマホの下に常に出るボタンも便利です。金額が一番右にあり、目の動きに慣れが要ります。
4. **案7** — 読みやすく、一覧の表が一番台帳らしいです。根拠が文章のままなので、説明は人の腕次第になります。
5. **案1** — 見積書の下書きらしさは良いです。ただ根拠の文章が長く、同じ数字が二か所に出て迷います。
6. **案3** — 文字が薄くて細く、「満点122点→100%正規化」のような分からない言葉もあり、試作品に見えます。
7. **案5** — 中身の説明の仕方は良いのに、見た目が売り込みのホームページです。毎日の見積作業には使わせません。

**どの案でも、先に直してほしい所**: 内訳の検算が合うようにすること。版代を含めた合計を出せるようにすること。特色の仕事の根拠に4色の仕事しか出てこない理由を示すこと。部数が大きく違う案件の扱いを見直すこと。この4つが直らないと、どの画面でも担当に「この数字で出していい」とは言えません。
