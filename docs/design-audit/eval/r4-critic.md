## 案ごとの「直さないと使えない所」上位3つと第一印象

### 案1
- 第一印象: 3列に詰め込んだ業務画面です。全部見えますが、狭く感じます。
1. 主PC1 右列: 確定金額の欄の入力例「31000」が右揃えで、入力済みの値に見えます。叩き台の後の主な作業は記録ですが、PCではその「確定金額を記録する」ボタンが枠線だけで目立ちません。
2. 主PC1 中央: 自動で完結しない条件の枠の文が長いです(1文が40字超、12〜13pxの細かい字)。3列のため、根拠の各行も折り返しが多くなっています(「チラ/シ」)。
3. 橙が多くの意味を兼ねています(主ボタン・金額・「変更」・特色1C)。状態「古くなった」では橙の塗りボタンが2つ同時に出ます。

### 案2
- 第一印象: 飾りの少ない縦積みの入力フォームです。見積の道具としての目的が伝わりにくいです。
1. スマホ: 叩き台の金額が主ス2の下端まで出てきません。記録は主ス5〜6で、下に固定のボタンもありません。最初の画面にはボタンが1つも見えません。
2. 一覧と登録が画面の左上に貼り付いた別窓になっています(一覧・登録PC)。一覧は表ではなく、下線リンクが並んでいるだけです。登録は下端が切れていて、保存とやめるが見えません。
3. 内部の言葉が画面に出ています(主PC3「満点122点→100%正規化」、欄の補足「(系統でスコア)」)。チェック箱も約20pxと小さいです。

### 案3
- 第一印象: 案1を整理し、金額と記録を最初の画面に収めた案です。
1. 主PC: いちばんの売りである「根拠」が、最初から畳まれています。見えるのはチップの「E-003 92%」だけで、開かないと理由が分かりません。
2. 主PC右・主ス2: 「確定金額の記録」の見出しが欄の名前と同じ大きさで、区画として見つけにくいです。
3. 入力例「31000」が値に見える点、橙の兼用、状態「古くなった」で橙の塗りボタンが2つ出る点は、案1と同じです。

### 案4
- 第一印象: LP のような紺の帯と特大の見出しです。業務の道具に見えません。
1. 主PC1: 叩き台の金額が画面の下(約800px)まで出ません。間に特大の見出し「過去見積38件から…」と飾りの「38→4」が入り、場所を取っています。
2. スマホ: 記録のボタンが主ス4まで出てきません。最初の画面の操作は「一覧」だけで、タブは文字だけなので押せる所か分かりにくいです。
3. 一覧PC1: 削除の確認で「削除する」が左、「やめる」が右になっています。右上の白塗りボタンと橙の主ボタンが並び、主の操作が2つに見えます。

### 案5
- 第一印象: 案4を明るい地にした案です。読みやすくはなりましたが、作りは LP 寄りのままです。
1. 主ス1: 叩き台の金額が最初の画面に無く、上の白塗り「過去見積 38件」(名詞のボタン)が主ボタンに見えます。記録も下に固定されていません。
2. 一覧: 削除の確認が「削除する/やめる」の逆の並びです。編集・削除は細い下線リンクで、押せる大きさが足りません。
3. 橙が金額・類似度・必須・「変更」を兼ねています。欄の名前・チップ・数字がほぼ全部太字で、強弱がありません。

### 案6
- 第一印象: 案2を詰めて整えた、普通の業務画面です。目立った破綻はありません。
1. スマホ: 記録のボタンが主ス4の下まで出てきません。下に固定の保存がありません。
2. 一覧PC1: 削除の確認が逆の並びです(「削除する」が左)。末尾の「ほか26件(下へ続く)」は、どう見ればよいか分かりません(ページ送りが無い)。

### 案7
- 第一印象: 「紙の控え」に見立てた装飾的な案です。呼び名と飾りがかえって邪魔をしています。
1. 呼び名が揺れています(叩き台/下書き/控え/控えの綴り/No.)。同じ物かどうか迷います(主PC1、状態、登録スマホ「控えを書く」)。
2. 主PC1 左帯: 条件・メモ検索・一覧・登録を1列に詰め込んでいます。白塗り「メモを検索する」が橙の主ボタンと張り合い、主ボタンの文字は「叩き台を/作る」と折れています。スマホは記録が下に固定されず、最初の画面の操作は名詞の「一覧」だけです。
3. 紙の角の印と点線の枠が多く、区切りが読みにくいです(主PC1・2、主ス3)。一覧の削除の確認も逆の並びです。

1. **案1**: 根拠・金額・記録が1画面に並んでいます。スマホは下に固定の記録ボタンとタブがあり、一覧は表です。削除の確認の並び、状態の見本もそろっています。直すのは入力例・橙の兼用・字の小ささが中心です。
2. **案3**: 案1の良い所をそのまま持ち、金額と記録を最初の画面に収めています。ただ、売りの「根拠」が最初から畳まれているため、案1より下にしました。
3. **案6**: 素直な作りで破綻が少なく、一覧は数字が右揃えの表です。スマホで記録まで遠いこと、削除の確認の並びが逆なことが残ります。
4. **案5**: 根拠の出し方(手順の番号・単価の並びの図)は分かりやすいです。ただ、スマホの最初の画面に金額が無く、主ボタンが2つに見え、削除の確認の並びも逆です。
5. **案7**: PCでは金額が最初の画面に入ります。ただ、呼び名の揺れと飾りの多さが、業務の道具として致命的に近いです。
6. **案4**: LP 調で、PCは金額まで遠いです。スマホは記録まで遠く、紺の帯の切り替えも見づらいです。
7. **案2**: スマホで結果まで6画面分あります。最初の画面にボタンが無く、内部の言葉が出ていて、一覧と登録の別窓も粗いです。
