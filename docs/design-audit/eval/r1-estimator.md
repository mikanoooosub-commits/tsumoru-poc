# 画面案の評価(宮下 紀子・見積担当として)

前提として、7案すべてで中身のデータは同じです(叩き台 ¥12,529・根拠4件・特色の注意・E-003 の手戻り)。違いは並べ方と見せ方だけなので、評価もそこを見ています。

**7案に共通して困ること(案ごとの欄では繰り返しません)**
- **根拠の4件がすべて4色の案件です。** どのカードも「× 色」になっています。特色1色の案件が1件も入っていないので、社長に「特色の仕事なのに、4色の単価から出したのか」と聞かれたら答えられません。一覧には E-035「特色1C封筒」や E-033・E-034 といった特色の案件があるのに、種類が違うので引かれていません。
- **E-037(30,000部・2.6円/部)が根拠に入っています。** 部数が10倍の案件です。中央値を使うので影響は小さいと思いますが、お客さんに「3万部の単価が混ざっている」とは言いにくいです。
- **型・版代が「別途(叩き台には含みません)」です。** 特色1Cなら版代は必ずかかります。¥12,529 をそのまま返事に使うことはできません。合計に入れるか、少なくとも「版代を足してください」と目立たせてほしいです。
- **特色の注意(追加納期+2日・特色番号を別途指定)が金額に反映されていません。** 注意は読めますが、読んだあと何をすればいいのか(色校正の費用を足すのか、納期を延ばして伝えるのか)が書かれていません。
- **注意の中身はネット印刷(グラフィック)の決まりです。** 「片面2色まで/45kg用紙は不可」は、うちの工場の話かどうか一瞬迷います。「ネット印刷では」と書いてあるので最後には分かりますが、「だからうちで受ける価値がある」という意味だと読み取れるまで、少し時間がかかりました。
- **確定金額の欄の「31000」は、入力例(グレーの薄い字)のはずです。** 叩き台が ¥12,529 なのに 31000 と出ていると、「もう誰かが入れたのか」「計算が違うのか」とドキッとします。案5・案7は右寄せなので、特に入力済みに見えます。
- **記録欄に案件名・お客様名・日付・担当者がありません。** 記録先は「チラシ/A4/コート90/特色1C/3,000部」と条件だけです。同じ条件の引合いが2件あったら、どちらの記録か区別できません。
- 記録した確定金額が、次から「過去見積」として類似検索に使われるのかは分かりません。登録画面では「原価」が必須ですが、記録欄に原価はありません。
- 過去見積の登録では原価が必須です。古い見積控えには原価が残っていないものも多く、Excel から入れ直す手間を考えると身構えます。
