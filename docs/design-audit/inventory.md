## 2. 見積担当(persona ② 宮下さん)の作業の流れと、今の画面でつまずく所
流れ: 引合いを受ける → 条件を入れる → 叩き台と**根拠の過去案件**を読む → 判定の帯・手戻りを確かめる → 金額を直して決める → 確定金額と補正理由を記録 → 後日、メモを語句で探す。過去見積を足す・直すのは別の時間。

| # | 場面 | つまずき(測った値・見た事実) | 由来 |
|---|---|---|---|
| J-1 | 条件を入れる(PC) | 1280×900 の画面で、主ボタンの上端が **y=940**(最初の画面の外)。8項目+チェック6つが縦に1列で並ぶ | 計測 |
| J-2 | 結果を見る(スマホ 375) | ページの高さ **5,329px**。主ボタン y=1,041 → 叩き台の金額 y=1,825 → 根拠の過去案件 y=3,166 → 記録 y=4,388。押しても結果へ移らない | 計測・F-25 |
| J-3 | 「アーカイブから根拠」が伝わるか | 根拠の過去案件は右の列の2番目。叩き台のカードの中の「価格根拠」は長い文章(約200字)。**「過去の何件から引いたか」が、金額より後に、文章で出る** | 目視(b02・b03) |
