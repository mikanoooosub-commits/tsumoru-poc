# test-scenarios — 画面確認の記録(つもる ― 見積アシスト PoC)

実施: 2026-10-12(WO-002) / 対象: ローカル `npm run dev`(Next.js 16.3.0・Turbopack・`localhost:3000`)、および本番URLの読み取り確認
環境: Chromium(Playwright・1280×900)で操作。結果と画面を記録した。スクショは [screenshots/](screenshots/)。

- ✅ = 画面で確認し期待どおり / ⚠️ = 動くが気になる点あり(issue-log に起票) / ⏭️ = 未確認(理由つき)
- **本番と同じ Neon DB を共有しているため、書込みを伴う確認(登録・更新・削除)は実施していない**(⏭️)。確認したのは読み取りと、DBに書かれる前に弾かれる検証のみ。
- 確認用データはすべて合成(仮)データ(「サンプル商店」・架空の案件名)。
