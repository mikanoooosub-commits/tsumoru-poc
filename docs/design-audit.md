## 3. 記録欄の常時表示(D52 判断2)

**現状**: 記録欄は結果エリアの中の折りたたみ「▸ 詳しく見る」にあり、叩き台を出すまで存在しない。再読み込み直後は、保存済みの記録が見えない。

**案**: 結果エリア(右カラム)の**下に、常時表示の帯**を置く。結果の有無に関わらず、同じ場所に出る。折りたたみ(`details`)は廃止する。

```
〔入力カード〕 │ 〔結果エリア〕
              │   結果なし: 「条件を入れて…」(1枚の案内)
              │   結果あり: 判定/叩き台/手戻り │ 類似案件
              │ ─────────────────────────────────
              │ 〔確定金額の記録〕   │ 〔メモを検索〕     ← 常時表示
              │  入力(叩き台なし=無効)│                    
              │  保存済みの記録 10件   │                    
              │ 〔削減効果〕(結果があるときだけ)
```

- 記録欄のフォーム: 叩き台がないときは入力を無効にし、**理由を書く**(「条件を入れて『叩き台を作る』を押すと、確定金額を記録できます」)。叩き台があるときは「記録先: チラシ / A4 / … 叩き台 ¥11,791」を見出しの下に出し、何に対する記録かを分かるようにする(表示のみ。保存する内容は変えない)。
- 保存済みの記録(直近10件)は常時見える。これで再読み込み直後から、叩き台との差を見返せる。
- メモ検索も同じ帯に置く(折りたたみの中にあるため)。検索の機能は変えない。
- 375px では帯は縦積み(入力 → 結果 → 記録 → 検索 → 削減)。

代替案(不採用): 画面の下に固定バーで常時出す → 375px で入力を隠す・押す場所が増える。叩き台の直下に置く → 叩き台が出るまで場所がなく、履歴が見えない。

## 4. 実装の順序(WO-009-2)

1. トークン(`:root`)と文字・太さ・書体・フォーカスを置き換える(1 ファイルで、全画面に効く)。
2. 部品(ボタン・入力・チップ・帯・メッセージ)のクラスを揃え、インライン style を外す。
3. 構造(`<main>`・`<h1>`・ラベル結び・記録欄の常時表示・メッセージの記号)。
4. 文言。

## 7. 判断を求める点(PM へ)

- **P-1 ダークテーマの扱い**: 現状は OS の設定で全面ダークに切り替わる。design-tokens は「今回は決めない」。案: ライトのみにする(ダーク用の値を削除)。影響: ダーク設定の端末で見た目が変わる。デモはライト想定。
- **P-2 エラー・削除の色**: design-tokens にエラー/削除用の色がない(「新しい色を発明しない」)。案: 既存の値の流用 — `#8A2E2E`(不明の文字色・白 8.36:1)と `#FDEAEA`(地)。**意味の流用(「不明」の印と同じ色)になる**ので、tokens 側で「エラー・削除」を足すか、流用してよいかの判断が要る。
- **P-3(参考・判断不要)**: 主ボタンを `accent-text`(橙)でなく `ink`(紺)の塗りにする案。理由: 「1画面に主役の色は1つ」(tokens 原則)で、橙は叩き台の金額に使うため。橙の塗りボタンを希望する場合は変えられる(白文字 5.21:1)。
